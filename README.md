# 3d-surface-plot-explorer

This is a small project I originally made in high school when I was learning Calc 3 and wanted a way to visualize 3D surfaces. It helped me understand how multivariable functions behave in 3D.

The program lets you type any function f(x, y) and see:
- A 3D surface plot
- A contour map
- Color‑mapped height visualization

To Run: python3 main.py

Example input:
- f(x, y) = sin(x) * cos(y)
- xmin = -5
- xmax = 5
- ymin = -5
- ymax = 5
- density = 60

Libraries Used:
- NumPy
- Matplotlib
